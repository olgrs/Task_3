# Task_3

Автоматизированные UI-тесты для веб-приложения Stellar Burgers (https://qa-stellarburgers.education-services.ru/).  
Проект покрывает основные пользовательские сценарии: восстановление пароля, личный кабинет, конструктор бургера и лента заказов.

## Тестируемые сценарии

### Восстановление пароля
- переход на страницу восстановления пароля по кнопке «Восстановить пароль»
- ввод почты и клик по кнопке «Восстановить»
- клик по кнопке показать/скрыть пароль делает поле активным — подсвечивает его

### Личный кабинет
- переход по клику на «Личный кабинет»
- переход в раздел «История заказов»
- выход из аккаунта

### Основной функционал
- переход по клику на «Конструктор»
- переход по клику на «Лента заказов»
- всплывающее окно с деталями ингредиента при клике на ингредиент
- закрытие всплывающего окна кликом по крестику
- увеличение каунтера ингредиента при добавлении в заказ
- залогиненный пользователь может оформить заказ

### Лента заказов
- открытие всплывающего окна с деталями заказа при клике на заказ
- заказы из «Истории заказов» отображаются в «Ленте заказов»
- при создании нового заказа увеличиваются счётчики «Выполнено за всё время» и «Выполнено за сегодня»
- после оформления заказа его номер появляется в разделе «В работе»


## Запуск тестов

1. Установите зависимости:
   pip install -r requirements.txt
2. Запустите тесты в браузере Chrome:
   pytest tests/ --browser=chrome --alluredir=allure-results
3. Для запуска в Firefox:
   pytest tests/ --browser=firefox --alluredir=allure-results
4. Просмотрите Allure-отчёт (если установлен Allure commandline):
   allure serve allure-results

## Особенности реализации

- Page Object Model: все элементы страниц описаны в отдельных классах, локаторы вынесены в отдельные файлы.
- Кросс-браузерность: тесты могут запускаться в Chrome и Firefox (параметр --browser).
- Явные ожидания: используются WebDriverWait, отсутствуют sleep и неявные ожидания.
- Независимость тестов: каждый тест использует уникального пользователя, создаваемого через API перед тестом и удаляемого после.
- Обработка перехвата кликов: для элементов, перекрываемых другими элементами, используется JavaScript-клик и drag-and-drop через JavaScript.
- Allure-отчёт: все ключевые шаги обёрнуты в @allure.step.

## Требования
- Python 3.12+
- Браузеры Google Chrome и Mozilla Firefox
- Пакеты: selenium, pytest, allure-pytest, requests
